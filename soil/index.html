Colorado Station Network

CoAgMET station data from coagmet.colostate.edu. RAWS stations from USFS site access records. SNOTEL stations from USDA NRCS's Air & Water Database (AWDB) REST API — no lab soil sample, live snowpack and (where sensored) soil moisture/temperature only.
Fractional Water Content layer

(Live VWC − lab Wilting Point) / (lab Field Capacity − Wilting Point), clamped 0–1. WP/FC come from each station's lab sample, matched to its shallowest depth. Shown only where a station has both a lab sample and a live sensor.

Recent Precipitation layer & chart

Marker size encodes the 7-day total. CoAgMET reports a daily total directly. RAWS's gauge reports a running cumulative reading, so daily totals are derived by differencing consecutive readings. SNOTEL uses its own daily Precipitation Increment field.

Saxton-Rawls
Depth Texture Sand % Silt % Clay % pH EC (mS/cm) %C %N C:N %CaCO3 %Inorg C BD (g/cm³) WP (%) FC (%) Sat (%) CF %

Saxton-Rawls: WP = Wilting Point, FC = Field Capacity, Sat = Saturation. All water values in %. BD = Bulk Density (real lab measurement, surface depth only where available). CF = Coarse Fragments (RAWS/SNOTEL only; — where not measured). A lab tag next to WP means that row is a real KSSL lab measurement, not a Saxton-Rawls model estimate. A BD tag next to FC/Sat means those values were adjusted using this row's real measured bulk density (Saxton-Rawls Eq. 6-10), not the texture-only model — WP itself is never adjusted for density.
